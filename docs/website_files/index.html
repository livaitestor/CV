Web Api

سیستم رزرو

این پروژه یک Web API احراز هویت‌محور برای سیستم رزرو منابع است که بر اساس معماری RESTful پیاده‌سازی شده. کاربران پس از ثبت‌نام و دریافت توکن JWT می‌توانند وارد سیستم شده و عملیات رزرو، لغو رزرو و مشاهده وضعیت منابع را انجام دهند. تمام اندپوینت‌ها با رعایت اصول REST (مانند استفاده از متدهای HTTP معنی‌دار، وضعیت‌های پاسخ استاندارد و ساختار URL منظم) طراحی شده‌اند و امنیت ارتباطات از طریق اعتبارسنجی توکن در هر درخواست محافظت می‌شود.
